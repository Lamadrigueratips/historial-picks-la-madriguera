# Historial de picks — La Madriguera 🦊

Registro público de los picks de La Madriguera. Diseñado para que ni siquiera
nosotros podamos reescribir el pasado sin dejar huella.

## Protocolo

1. Cada pick se registra AQUÍ **antes** de que empiece el partido: un archivo en
   `picks/` con fecha, partido, pick, cuota y hora de registro.
2. Cuando termina el partido, el resultado se **añade** al mismo archivo en un
   commit posterior. Lo ya registrado (pick, cuota, hora) no se modifica jamás.
3. Cada cambio queda sellado con fecha en el historial de GitHub. Reescribir un
   commit cambia su firma y rompe la cadena: cualquiera puede detectarlo.

## Cómo verificarlo

- Abre cualquier archivo en `picks/`.
- Pulsa **History**: verás el commit original con su fecha, anterior al partido.
- Compara con la fila correspondiente en la página pública.
