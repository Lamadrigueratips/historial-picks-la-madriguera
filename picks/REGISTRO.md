# Registro de picks

Cada archivo de esta carpeta es un pick: `AAAA-MM-DD-partido-mercado.md`.

- El archivo se crea **antes** del partido (compruébalo en la fecha del commit).
- El resultado se añade **después**, en un commit nuevo, sin tocar lo registrado.
- Nada se edita. Nada se borra.

Aún no hay picks registrados: el registro empieza con el primer pick publicado
el 29-09-2026 o después.
